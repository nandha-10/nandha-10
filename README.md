## 🚀 Featured Engineering Projects

### 🦾 1. 6-DOF Robotic Arm
- **Overview:** Designed and fabricated an articulated 6-DOF robotic manipulator powered by an ESP32 and six servo motors.
- **Key Features:** Wireless Bluetooth control via mobile interface, multi-servo synchronization, and real-time status feedback on an onboard LCD.
- **CAD & Mechanical:** Kinematic linkage and structural components modeled in SolidWorks.
- **Tech Stack:** `ESP32` • `Arduino` • `Servo Motors` • `Bluetooth` • `LCD Display` • `SolidWorks`

---

### 🏎️ 2. ROS2 Maze-Solving Robot
- **Overview:** Engineered an autonomous mobile robot capable of navigating and solving unknown maze environments.
- **Navigation Logic:** Implemented a real-time left-wall-following algorithm orchestrating sensor data with motor drivers.
- **System Architecture:** Integrated ROS2 for node communication with Arduino for low-level actuation.
- **Tech Stack:** `ROS2` • `Arduino` • `Sensors` • `C / C++` • `Autonomous Navigation`

---

### 🤟 3. Sign Language to Speech System
- **Overview:** Developed an assistive system translating hand signs into spoken words in real time.
- **AI / Deep Learning:** Trained a CNN achieving approximately **87% recognition accuracy**.
- **Platform:** End-to-end model development in MATLAB & Simulink.
- **Tech Stack:** `MATLAB` • `Simulink` • `CNN` • `Computer Vision`

---

### 👁️ 4. Eye-Blink Controlled Appliance System
- **Overview:** Created an assistive rig enabling hands-free control of household appliances for people with limited mobility.
- **Sensing Mechanism:** IR sensors on wearable glasses detect deliberate blinks while filtering involuntary ones.
- **Tech Stack:** `Arduino` • `IR Sensors` • `Embedded C` • `Circuit Design` • `Relay Automation`

---

### 🥽 5. VR-Based 3-Axis Robotic Arm
- **Overview:** Built a virtual reality control framework and digital twin for a 3-axis robotic arm.
- **Integration:** Unity for 3D visualization, SolidWorks for mechanical models, Arduino for servo control.
- **Tech Stack:** `Unity` • `SolidWorks` • `Arduino` • `Kinematics Simulation`

---

### ⚡ 6. Self-Charging EV with Rear Hub Generator
- **Overview:** Conceptualized an energy-recovery powertrain model for electric vehicles.
- **Mechanism:** Rear hub generator with DC-DC conversion to capture kinetic energy during transit.
- **Tech Stack:** `BLDC Motor` • `DC-DC Converter` • `Electrical Powertrain Systems` • `SolidWorks`
